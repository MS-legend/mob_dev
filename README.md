# 📸 SnapNote: Многофункциональное Демо Приложение

SnapNote — это демонстрационный проект, разработанный на React Native с использованием фреймворка Expo. Приложение служит платформой для тестирования и демонстрации нативного функционала устройств (мультимедиа, хранилище, системные настройки) и лучших практик разработки (атомарные компоненты, пользовательские хуки, динамические стили).

## ✨ Ключевые Функции

Приложение демонстрирует широкий спектр возможностей, реализованных через модульную структуру:

### 🏠 Главный Экран (Home)
* Централизованная навигационная панель для доступа ко всем модулям.

### 🎥 Мультимедиа (MediaScreen)
* Работа с Камерой: Возможность делать новые фотографии.
* Галерея/Хранилище: Выбор изображений из локальной галереи устройства.
* Работа с Аудио: Запись голосовых сообщений и воспроизведение тестовых аудиосигналов.

### 🖼 Галерея (GalleryScreen)
* Персистентное Хранение: Сохранение выбранных и сделанных изображений с использованием локального хранилища (AsyncStorage).
* Учет Статистики: Автоматическое ведение счета добавленных фотографий.
* Просмотр: Полноэкранный просмотр добавленных изображений.

### 📊 Аналитика (AnalyticsScreen)
* Статистика: Отображение ключевых метрик приложения (например, общее количество сохраненных фотографий).
* Анимации: Демонстрация плавных анимаций для визуализации данных.

### ⚙️ Настройки (SettingsScreen)
* Динамическая Тема: Переключение между светлой и темной темой (с мгновенным применением ко всем экранам).
* Управление Состоянием: Демонстрация сохранения и управления различными булевыми настройками (уведомления, автосохранение, вибрация).
* Сброс Данных: Возможность очистки локального хранилища (счетчики, галерея).

## 💻 Технологии

* Фреймворк: React Native
* Платформа: Expo
* Язык: JavaScript (ES6+)
* Ключевые библиотеки:
    * expo-av (Аудио)
    * expo-image-picker (Изображения/Камера)
    * @expo/vector-icons (Иконки)
    * Пользовательские хуки (useStorage, useApi)
